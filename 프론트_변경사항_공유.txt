===== PitchMate 서버 변경사항 (2026-04-17) =====


1. 영상 파일 저장 방식 변경
--------------------------------------
- 기존: Railway 서버 로컬 디스크에 저장 → 서버 재시작 시 파일 사라지는 문제 있었음
- 변경: Supabase Storage에 영구 저장

- videoUrl 형식 변경
  기존: /videos/uuid_파일명.mp4  (상대 경로)
  변경: https://gemeljbpyavcutbzcujj.supabase.co/storage/v1/object/public/videos/uuid.mp4  (절대 URL)

→ 영상 재생 시 videoUrl을 그대로 src에 넣으면 됩니다.


2. 루브릭별 AI 코멘트 응답 추가
--------------------------------------
- 기존: 평가 조회 시 scores 배열에 rubricId, rubricTitle, score 만 있었음
- 변경: comment 필드 추가됨

변경 후 scores 항목 구조:
{
  "rubricId": 1,
  "rubricTitle": "발음 정확성",
  "score": 8,
  "comment": "전반적으로 발음이 명확하나 일부 단어에서 개선이 필요합니다."  ← 추가됨
}

→ 히스토리 상세 화면에서 루브릭별 AI 코멘트 표시 가능합니다.


3. 영상 업로드 시 AI 자동 실행 항목 추가
--------------------------------------
- 기존: 영상 업로드 → AI 분석 자동 시작, AI 평가 자동 시작
- 변경: 영상 업로드 → AI 분석 자동 시작, AI 평가 자동 시작, AI 피드백 자동 시작

→ 업로드 후 별도로 피드백 API를 호출할 필요 없습니다.
→ 분석/평가/피드백 모두 비동기로 처리되므로 업로드 응답은 즉시 옵니다.
   완료 여부는 analysisStatus로 확인하세요. (PENDING → IN_PROGRESS → COMPLETED)


4. AI 평가 중복 생성 방지
--------------------------------------
- 기존: AI 평가 API를 여러 번 호출하면 평가가 중복 생성됨
- 변경: 이미 AI 평가가 존재하면 기존 평가를 그대로 반환

→ 프론트 동작 변화 없음.
